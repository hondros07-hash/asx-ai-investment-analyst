# V14 — Multi-Indicator Technical Analysis Lab

Rebuilds the Technical workspace with a selectable indicator library, multiple simultaneous indicators, candlestick overlays, separate oscillator panels, per-indicator explanations tied to the selected share, and combined multi-indicator interpretation.

Included families:
- Trend/overlays: SMA 20/50/200, EMA 20, Bollinger Bands, rolling VWAP, Donchian, Keltner, Ichimoku, Parabolic SAR.
- Momentum: RSI, MACD, Stochastic, CCI, Williams %R, ROC, Momentum.
- Strength/volatility: ADX/DMI, ATR.
- Volume/flow: Volume, OBV, MFI, CMF.

The combined reader explicitly warns against double-counting correlated indicators and teaches a trend + momentum + participation + volatility/strength framework.
