# Axía visual rebrand

Customer-facing Chrímata/CHRÍMATA text is changed to Axía/AXÍA in the Streamlit app and Next.js frontend. The existing photographic banner is retained with a CSS/SVG overlay masking the legacy wordmark. Internal `chrimata` identifiers, asset filenames, migrations, API routes, environment variables and historical references remain unchanged for compatibility. No trademark/domain availability is asserted.

Baseline: V23.4.6, the latest complete artifact available here. Previously requested V23.5.0 and V23.4.6.1 are not included because no completed full-project artifact was available.
