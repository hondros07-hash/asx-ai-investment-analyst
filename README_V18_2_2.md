# V18.2.2 — Command Centre Forecast

The Forecast Research tool is now rendered directly inside Company Command Centre.

Order:
1. Company Snapshot
2. Analyst Consensus
3. Forecast Research — 1M / 3M / 6M / 12M
4. Your Position
5. Attention / Thesis / Market Structure / Valuation / Announcements / Catalysts

The separate Forecasts workspace remains available in the application.

Forecast outputs:
- current price
- median forecast
- 20th percentile historical downside case
- 80th percentile historical upside case
- median return
- historical positive-return frequency
- sample size
- forecast path chart

The forecast remains explicitly labelled research and is not an investment recommendation.
