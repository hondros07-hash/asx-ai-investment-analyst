# V10.4 — ASX + NASDAQ + NYSE

V10.4 extends the unified analyst to US-listed equities.

## Added
- NYSE support
- NASDAQ support retained/expanded
- ASX support retained
- Automatic market/exchange identification from provider metadata
- Currency and exchange display on the company dashboard
- Market-aware default benchmark
- Comparison options: ASX 200, S&P 500, Nasdaq 100, Dow Jones, custom ticker
- Bare US symbols such as AAPL, JPM and KO are accepted
- Explicit ASX symbols such as ZIP.AX and BHP.AX are accepted
- Data & Production market-coverage panel

## Data
Twelve Data remains the intended US/FX live-data provider where the user's plan permits.
Yahoo/yfinance remains a development/research fallback. True ASX real-time data still requires
an appropriately licensed ASX data source.

## Important
Data freshness and redistribution rights are determined by the active provider and exchange licence.
