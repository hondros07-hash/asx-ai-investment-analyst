# V13.1 — Contextual Hover Help

This build adds native Streamlit hover-help to metric cards through one central `metric_box()` wrapper and `METRIC_HELP` glossary.

Covered cards include Market, Exchange, Currency, benchmark, Price, session/52-week statistics where rendered as metrics, RSI14, performance periods, Sector, Industry, benchmark comparison, reverse DCF growth, volatility, drawdown, Sharpe and momentum.

Because the glossary is centralised, additional metric explanations can be added without rewriting individual screens.
