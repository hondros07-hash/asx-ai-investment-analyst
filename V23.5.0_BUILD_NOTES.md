# Chrímata V23.5.0 — Quantitative Forecast Summary & Model Accountability Engine

Built from the latest verified complete V23.4.6 archive. The previously requested V23.4.6.1 valuation recovery build was not available as a completed archive and is not represented as included here.

- The dashboard summary consumes the same canonical `build_12m_forecast` result as the Full Forecasts page.
- `GET /api/v1/widget/forecast-summary?ticker=...` executes via the existing FastAPI threadpool.
- Return delta is calculated deterministically against the supplied reference price.
- Validation metadata, provenance, missing-input reason, and model version are exposed.
- The canonical engine provides only a 12-month endpoint, not a monthly forecast trajectory. The previously decorative sparkline is replaced by a truthful path-unavailable state. No synthetic monthly points are presented as model output.
- Live provider and browser visual verification have not been performed.
