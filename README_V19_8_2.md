# Chrímata V19.8.2 — Terminal Landing Page

This build converts Home into the compact terminal-style landing page approved from the visual concept.

- Chrímata + Parthenon hero banner embedded directly in `app.py` (no external asset path required).
- Browser tab title remains `Chrímata` with the Parthenon icon.
- Compact global market selector: Australia, United States, United Kingdom, Japan, Hong Kong and Canada.
- Major-index cards plus FX and gold snapshot.
- Main market chart, sector performance and index performance in one dense row.
- Gainers, fallers, watchlist and volatility/risk in one row.
- Dividends, earnings, global markets, FX, commodities and verified-data-safe IPO panel.
- Existing research, company, thesis, forecast, portfolio and monitoring functionality retained.

Data note: market data is provider dependent and may be delayed. Movers rank the configured sample universe for each market rather than claiming an exchange-wide scan. Missing calendar/sector/IPO data is shown as unavailable rather than fabricated.
